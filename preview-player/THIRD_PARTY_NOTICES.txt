Majdata preview player
======================

This distribution includes a WebGL build of MajdataView with ZPPZ
record-mode playback changes, plus the minimal bridge required to load
user-authorized chart assets.

MajdataView (upstream)
----------------------
Project: https://github.com/TeamMajdata/MajdataView
License: GNU General Public License v3.0 (GPL-3.0)
Pinned upstream commit: ad734f1272159a52cbd948c27c68cfa7cf1dc536

ZPPZ record-mode fork
---------------------
Source of the playback changes (SongDetail intro, delayed start, All Perfect,
clock_count) lives in this repository under:

  preview-player/majdata-view-record/

Apply the patch from that directory onto the upstream commit above, build
WebGL with Unity 6000.3.17f1, then publish via scripts/publish_preview_player.py.
Recommended independent GitHub repository name when you push the fork:

  MajdataView-zppz-preview
