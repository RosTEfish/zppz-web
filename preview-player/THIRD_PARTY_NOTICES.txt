Majdata preview player
======================

This distribution includes a WebGL build of MajdataView with ZPPZ
record-mode playback changes, plus the minimal bridge required to load
user-authorized chart assets.

ZPPZ record-mode fork
---------------------
Playback changes (SongDetail intro, delayed start, All Perfect, clock_count)
and Unity 6000.6 editor API fix live under:

  preview-player/majdata-view-record/

SongDetail is loaded from Assets/Resources/SongCover at runtime. The currently
pinned WebGL build is `majdataview-zppz-record5-webgl-6000.6`
(SongDetail via Resources/SongCover ScreenSpaceOverlay).

WebGL was built with Unity Editor 6000.6.0f1 (WebGL module) from that patched
tree. Corresponding source is published as corresponding-source.zip beside
the player. Local fork checkout used for the build:

  ~/MajdataView-zppz-preview (branch zppz-record-mode)
